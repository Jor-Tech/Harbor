# Harbor 0.4.0-alpha.13

This candidate prepares Harbor's public source release under the MIT License and adds user-controlled update checks. Installers are available only after the release workflow completes successfully.

- **Check now:** check public GitHub releases from Settings → Releases & updates.
- **Automatic checks:** optional checks shortly after launch and every 12 hours while Harbor is running. Off by default; the setting stays on this device.
- **Preview selection:** choose whether alpha, beta and other prereleases are included. Only published releases with an installer for the current platform and architecture qualify.
- **Update notification:** a compact titlebar button opens Settings when a newer version is available. The download button opens that release's GitHub page.
- **Clear failures:** network errors, unavailable public releases and rate limits are reported without claiming the app is up to date.
- **Public documentation:** MIT licensing, third-party notices, current setup guidance and a device-validation checklist accompany the source.

Checks do not send vault contents, saved hosts or credentials. GitHub receives the public network request. Harbor does not automatically download, install or restart. Quit Harbor, install the appropriate package and reopen it; existing vault paths, vault format and MCP permissions are unchanged.

This remains an unsigned preview (macOS ad-hoc signed, not notarized). The release pipeline must validate all four desktop targets and the complete installer set before publication. Real password-manager, suspend/resume and interactive installer behavior still require [device checks](../validation.md).
